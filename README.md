## Installation:

1. Download melonloader:
https://melonwiki.xyz/
(You don't need bleeding edge anymore, latest stable will work.)

2. Install it to your miside zero installation using the installer. 
Click add game manually and select the miside zero exe.

3. Download the latest version from Github Releases. 
For those of you who have somehow never used Github before, 
you click the zip file in assets.

4. Extract the zip to your Mods folder.
